# MysInfo
Finds misinformation using Google Gemini.

# STEPS

Install Node.js

Install filesx or fileswindows depending on your operating system. (filesx has no extension, fileswindows has .bat)

Run installpkg in the terminal

Run api in the terminal

Open [Localhost Port 3000](http://localhost:3000) or which the port which displays in the terminal if it is not 3000.

Open [Google AI Studio](https://aistudio.google.com/api-keys)

Make an API Key

All set!
